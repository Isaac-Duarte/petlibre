# Documentation

The docs follow the code's split. Facts about a **chip** hold for every board built on it. Facts about a **device** hold for one feeder model and its stock firmware. The **firmware** docs describe Wellfed's own replacement, which isn't tied to one device. Adding a model adds a folder under `devices/` and reuses the rest. Every finding carries an [evidence level](evidence.md), and outside sources are listed in [references](references.md).
